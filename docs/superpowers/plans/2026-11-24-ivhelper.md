# ivHelper Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Une app Flutter qui lit l'écran d'évaluation de Pokémon GO et affiche le rang PvP en ligue super (1500) et hyper (2500), avec une pastille flottante sur Android et un parcours par capture d'écran sur iPhone.

**Architecture:** Cœur en Dart pur (formules, table de rangs, inférence d'IV, analyse du texte lu), testé sans Flutter. Une couche de lecture d'écran (ML Kit) et une interface (panneau Super/Hyper) au-dessus. Deux déclencheurs : service Android natif (pastille et capture) et import de la dernière capture sur iOS.

**Tech Stack:** Flutter stable, Dart 3, `flutter_riverpod`, `google_mlkit_text_recognition`, `flutter_overlay_window` (Android), `photo_manager` (iOS), GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-24-pvp-rank-overlay-design.md`

## Global Constraints

- Plafond de PC : 1500 (super) et 2500 (hyper). Niveau maximal 51 (niveau 50 plus bonus meilleur ami), niveaux par demi-pas depuis 1.
- 4096 combinaisons d'IV (0 à 15 pour attaque, défense, PV). Rang par produit des stats, pourcentage = produit / meilleur produit.
- Tout se calcule sur le téléphone, hors ligne. Aucun identifiant du jeu demandé, aucune saisie automatique dans le jeu.
- Jamais de rang unique affiché quand plusieurs combinaisons d'IV restent possibles : afficher une fourchette.
- Textes de l'interface en français, noms d'espèces en français.
- Pas de Flutter ni de pub.dev dans le bac à sable de la session : tout test ou build se vérifie dans GitHub Actions (`gh run watch`).

## Review Focus

- Pokémon renommé : le nom lu n'est pas une espèce. Attendu : le panneau de correction s'ouvre avec l'espèce à choisir, sans rang erroné.
- Pokémon chanceux, obscur ou purifié : le coût en poussière diffère (moitié, +20 %, -10 %). Attendu : ces coûts sont aussi acceptés, jamais d'ensemble vide à cause d'eux.
- Pokémon au niveau maximal (pas de coût de montée en puissance) : attendu, inférence par PC et PV seuls, fourchette plus large.
- Lecture partielle (PC ou PV manquant) : attendu, formulaire de correction prérempli, pas de plantage.
- Capture qui n'est pas un écran d'évaluation : attendu, message « écran non reconnu », aucun rang.
